# Hotel Room Booking

College demo for booking a hotel room. Originally HTML + PHP + MySQL. This copy is static HTML and JavaScript so a reviewer can open it in the browser.

## Live demo

https://pardhu186.github.io/Hotel-Room-Booking-/

## Try it

1. Open `index.html` or the Pages URL.
2. Book Room Now, pick a city, fill the form, choose Single / Double / Deluxe.
3. Acknowledgement shows room number and amount (nights x 500 / 750 / 1000).
4. Pay with any account name and number. Status is stored in this browser.
5. Get Acknowledgement on the home page looks up the same name + password.

Original `.php` files stay in the repo as history and are not used by the live site.
